# NeiiPlay - Music Player Application

NeiiPlay adalah aplikasi pemutar media berbasis web yang dirancang menggunakan HTML, CSS, dan JavaScript DOM.

## Fitur

* Welcome Screen (Layar Selamat Datang)
* Home Screen
* Banner Artis / Penyanyi Favorit
* Daftar media (Recently Played)
* Pemutar video lokal bawaan di tab baru
* Responsive untuk desktop, tablet, dan mobile

## Teknologi

* HTML
* CSS
* JavaScript (DOM)
